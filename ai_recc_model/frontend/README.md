# AI-Based Course Recommendation System with Online Learning

## Project Description
This project is a search-based AI course recommendation system that dynamically learns from user behavior. When a user searches for a course, the system displays matching results along with related recommendations. The system continuously adapts based on user interactions using online learning.

## Problem Statement
Traditional recommendation systems rely on static models and do not adapt quickly to changing user interests. There is a need for a system that can provide contextual recommendations and learn continuously from user behavior.

## Proposed Solution
The proposed system integrates search functionality with an online learning-based recommendation engine. User searches and clicks are tracked in real time to update recommendations dynamically without retraining the entire model.

## Key Features
- Search-based course discovery
- Contextual recommendations
- Online learning from user behavior
- Larger dataset support
- Direct YouTube learning links
- Clean and interactive user interface

## Technologies Used
- Python
- Flask
- HTML, CSS, JavaScript
- REST APIs

## System Flow
1. User searches for a course
2. System displays matching search results
3. Related course recommendations are shown
4. User clicks are tracked as behavior
5. System learns and updates future recommendations
