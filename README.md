About the Course Recommendation System
This project is an AI-based Course Recommendation System designed to help users discover relevant computer-related courses efficiently. The system combines search functionality with intelligent recommendations and improves suggestions using user interaction data.

How This Project Was Built
Frontend designed using HTML, CSS, and JavaScript
Backend developed using Python Flask
Search-based recommendation logic implemented
User clicks tracked to improve recommendations (online learning)
Integrated YouTube links for direct learning
How the System Works
User logs into the system
User searches for a course
Matching courses are displayed
Related courses are recommended
User interactions improve future suggestions
